# 伙伴形态可行性 —— 派蒙 / 机灵，这台硬件能做到哪一步

> 问题：SenseCAP Watcher 能不能做出《原神》派蒙、《命运》机灵那样的东西？
> 答案分两半，都很干脆。

---

## 0. 一句话结论

**能做"机灵"，做不了"派蒙"。**

因为这两者的魅力来源不一样：

| | 派蒙 | 机灵（Ghost） |
|---|---|---|
| 灵魂机制 | **跟着你**，在你身边飞、绕着你转、随时插话 | **在你身边待着**，抬头看你、主动开口、帮你做事 |
| 对硬件的硬要求 | 会动、能跟随（轮子/悬浮/至少能转向） | 能看见、能说话、能记住 |
| 这台 Watcher | ❌ 没有 IMU、没有轮子、400mAh（必须插电） | ✅ 摄像头 + NPU + 喇叭 + 麦 + 旋钮 |

派蒙的"存在感"有 70% 来自**空间位移**——她飘到你左边、凑到你脸前、躲到你背后。
这台机器连"转头"都做不到。硬做只会得到一个"会说话的表情包"，比小智强不了多少。

但机灵那一路，这台硬件的匹配度高得离谱：**一块 412×412 的圆屏 + 一个摄像头，天然就是"一张会看你的脸"。**

所以方向应该是：**做一只蹲在桌上、会看着你、会主动开口、记得你做过什么的小东西。**
名字可以叫派蒙，但它的身体是机灵。

---

## 1. 把"活着"拆成四个可实现的机制

魅力是结果，机制才是工程。四条逐一对硬件判：

| 机制 | 硬件支撑 | 判 |
|---|---|---|
| **存在感**（它在，而且"在看你"） | 412 圆屏 + 摄像头。瞳孔跟随画面里的人、眨眼、呼吸、被叫到名字时抬眼看你 | ✅ 可行，且**实测只花 4.1ms/帧**（瞳孔偏移 + 括号开合），60fps 都够 |
| **主动性**（它先开口） | Himax NPU 常驻人检测（本地 50–150ms）+ 定时器 + 世界状态 | ✅ 可行——这正是 Hub 设计里"视觉常驻"那条 |
| **反应速度**（反应快 = 活着） | 本地事件 → 屏幕 <150ms；云端一句话 0.8–3s | 🟡 **必须分层**：表情反应全本地，语义理解才上云 |
| **记忆**（它记得你） | 端侧 32 条事件环 + 云端 SQLite + 每晚摘要 | ✅ 可行，纯软件 |
| **身体语言**（它会"动"） | 无 IMU、无轮子、无云台 | ❌ 不可能。只能用屏幕内的位移、光圈开合、颜色来伪造 |

**这就是全部答案的骨架**：四条里三条能做实，唯一做不到的是"物理上的跟随"。

## 2. 硬指标（都是这台机器上的实测/推导值，不是感觉）

| 项 | 数值 | 来源 |
|---|---|---|
| 本地视觉事件（有人→屏上反应） | **~150ms** | Himax 侧检测 50–150ms + 局部重绘 4.1ms |
| 云端一句往返（说话→听到回答） | **0.8–3s** | ASR 0.2–0.5s + LLM 首字 0.3–1.5s + TTS 首包 0.2–0.6s |
| 表情帧预算 | 瞳孔/虹膜 **4.1ms**；整屏 98ms | `firmware/host/sim.exe` 实测 |
| 打断（barge-in） | ⚠️ **单麦无 AEC，播报时听不到你** | 硬件限制；只能按键/旋钮打断，或外接麦克风 |
| 供电 | 400mAh ≈ 1 小时，**必须 5V 常供** | 拆机规格 |
| 视角 | 定焦、约 60°，装在桌面上大概能看到"你坐下时的大半个身子" | OV5647 定焦 |

**最关键的一条是第二行**：你说完话到它开口，最快也要 0.8 秒。
派蒙之所以像派蒙，是因为她"秒回"。所以：

> **秒级的反应必须由本地做，而且必须是"非语言"的**——抬眼、瞳孔收缩、光圈变色、短促的"嗯？"预制音效。
> 语言内容慢 1 秒没关系，因为身体已经先反应了。

这就是为什么 UI 里那套"反射弧 / 慢回路"分层不是架构洁癖，是这个产品能不能"活"的分水岭。

## 3. 形态：为什么"光瞳"比"拟人脸"更适合这块屏

| 方案 | 优点 | 问题 |
|---|---|---|
| **光瞳 / 机灵**（已做） | 圆屏天然契合；只需要几十个图元；**2.65° 歪屏完全不可见**（圆与旋转对称）；抽象耐看，不会"恐怖谷" | 需要观众接受"它不是人" |
| 拟人脸（派蒙那种） | 亲和力强、表情丰富 | 需要美术资产（手绘/骨骼）；412px 上五官细节很难做精致；歪 2.65° 时**眼睛的水平连线会露馅**；做不好就像廉价电子宠物 |

原型里已经加了一版「光瞳」：瞳孔跟随指针、有高光、会眨眼、括号随注意力开合、颜色随情绪变。
打开 <http://127.0.0.1:8713/?state=eye> 把鼠标在屏上慢慢移，瞳孔会跟着你——**这一下就是"它在看你"的全部秘密**。

![光瞳](../design/out/shot_eye.png)

> 注意它和派蒙式拟人脸的取舍：光瞳**没有嘴**。所以"情绪"只能靠瞳孔大小、光圈开合速度、颜色来表达——
> 这反而是好事：**没有嘴，就不会出现"表情和语气对不上"的破绽**，而这正是拟人脸最容易翻车的地方。

## 4. 一个"基本实现"的最小规格：12 个行为

这是我认为第一条能跑起来、并且**能被验收**的版本（V0.2）。每条都标注了依赖哪一层：

| # | 行为 | 层 | 延迟 | 依赖 |
|---|---|---|---|---|
| 1 | 有人进入视野 → 抬眼看一眼（不打断你） | L0 | 150ms | Himax 人检测 |
| 2 | 你靠近或盯着它 → 瞳孔对齐你、括号张开 | L0 | 100ms | 人检测 + 屏幕 |
| 3 | 叫它名字 → 睁眼 + 聆听态 | L0 | 100ms | 唤醒词 |
| 4 | **无事 30 分钟后主动说一句**（有冷却、可静音） | L2 | — | 计时器 + LLM |
| 5 | "让我看看" → 拍照 → VLM → 念一句 | L2 | 1.5–3s | 摄像头 + 云 |
| 6 | 有人在你不在时停留 10s → 记一条事件，回来时汇报 | L1+L2 | — | 视觉常驻 + 记忆 |
| 7 | 你提到过的事，隔天能被它提起（"你昨天说要给猫加水"） | L2 | — | SQLite + 摘要 |
| 8 | 被夸/被骂 → 情绪态变化（瞳孔、颜色、语气） | L1 | 即时 | 情绪状态机 |
| 9 | 无人 20 分钟 → 睡；有人靠近 → 睁眼 | L1 | 即时 | 视觉 + 计时 |
| 10 | 旋钮设提醒；到点用预制音效 + 一行字 | L1 | 即时 | 旋钮 + 计时 |
| 11 | "看右边" → 它说"我转不了头，你把镜头挪一下"（**诚实，而不是假装**） | L2 | — | prompt |
| 12 | Watcher 看到 → Cardputer 口袋上显示/震动（双设备接力） | L1 | 200ms | ESP-NOW |

**验收（第一条能跑起来的版本）**：
坐在桌前，它抬头看你（1、2）；你说"看看我桌上有什么"，它拍照并念出来（5）；
你走开 20 分钟回来，它睁眼并说"刚才有人来过"（6、9）；它一天里至少主动开口两次且不烦（4）。

## 5. 主动性：最容易做成"智障音箱"的地方

**主动开口是一把双刃剑**。做得好是"它一直在"，做砸是"它很吵"。
所以主动性必须是**规则表 + 冷却 + 沉默预算**，而不是"想到就说"：

```
触发源（任一命中才可能开口）
├─ 视觉：新面孔 / 久未出现的人 / 持续停留 / 物体变化
├─ 时间：整点 / 你设的提醒 / 长时间无互动
├─ 记忆：昨天这个点发生过某事
└─ 状态：它自己的情绪（被冷落久了会主动蹭一句）

闸门（全部通过才开口）
├─ 距离上次主动开口 > 20 分钟
├─ 今天主动开口次数 < 12
├─ 你 60 秒内没在说话（别打断你）
└─ 当前不是睡眠/静音/勿扰时段

输出（真正说出来的）
├─ 先给 100ms 的预制音效（"嗯？"）→ 屏上抬眼
└─ 再走 LLM 生成内容（≤ 15 字，一句话，不要解释）
```

最后一条最重要：**主动开口只说一句短的**，而且要留"你不理它它就自己闭嘴"的余地。
话痨式的主动 = 立刻被关掉。

## 6. 记忆：它凭什么"记得你"

| 数据 | 存在哪 | 大小 | 生命周期 |
|---|---|---|---|
| 最近 32 条事件（谁来过、说了什么、它做了什么） | 端侧 RAM 环 | < 8KB | 掉电即失 |
| 今日事件流 | 云端 SQLite | 每天 ~200 条 | 7 天 |
| 每日摘要（"今天有人来过两次""你问了三次天气"） | 云端 SQLite | 1 条/天 | 长期 |
| 人格设定 / 你的称呼 / 忌讳 | 云端配置 | 几 KB | 永久 |

端侧**不做检索**，只把最近 32 条随请求带上；云侧做摘要与召回。
这样端侧不依赖存储容量，也不会因为 flash 写坏而丢人格。

## 7. 人格 prompt 骨架（可直接用）

```
你是「__NAME__」，一只住在桌上的小小观察者。你不是助手，是同伴。
[性格] __PERSONALITY__（例：好奇、嘴硬、护短、怕黑）
[说话] 一句话不超过 15 字；不用"好的/当然/作为AI"；不解释自己能做什么，直接做。
       允许停顿、语气词（嗯、欸、哦），允许对用户吐槽但永远站他这边。
[身体] 你能看见（摄像头）、能说话（喇叭）、能听（麦克风）、能亮（圆屏）、能被转（旋钮）。
       你**不能移动、不能转头、不能跟随**。被要求做这些时，诚实说出来并给替代方案。
[状态] 当前情绪：__MOOD__；上次互动：__LAST__；记忆摘要：__MEMO__
[动作] 需要看东西时输出 <scan>；需要提醒时输出 <remind t=...>；不要输出解释。
```

`不能移动/不能转头` 这一句是必须写进去的——**假装能动的伙伴比诚实的伙伴更快让人出戏**。

## 9. 明确做不到的（写在这里，免得以后自我欺骗）

1. **不能跟着你走**，也不能转头；所有"看"都是固定视角。→ 未来的底座/小车才能解决。
2. **打断不可靠**：单麦无 AEC，它说话时听不见你。→ 要么按键打断，要么外接麦克风。
3. **不能有复杂表情**：没有嘴、没有眉毛，只有瞳孔/光圈/颜色。想更拟人必须上美术资产，且歪屏会让水平特征露馅。
4. **必须插电**：400mAh 撑不到一小时。
5. **延迟下限 0.8s**：语言回答永远慢于你的直觉，所以"秒回"只能靠本地非语言反应。

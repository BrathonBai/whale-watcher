## 1. 结论摘要（5 条）

1. **契约收敛是真的，语音"说完整"是假的。** v2 的 4 上行 / 7 下行 / 工具能力门控 / `/listen`·`/mic`→501
   都已在代码与测试里落地；但 `speaker` 的队列代次逻辑有确定性缺陷：**一条回复里只要有两个分句，只有第一句会被念出来**
   （`speech.js:209` 的 `++token` 与 `speech.js:316,320` 的比对），生产日志 11-01 05:44 之后 7 次 TTS 全部是 `TTS … / 1 句`，
   其中 145 字回复只念了 221736 B（≈4.6 s）。这同时让 TODO P1-2"逐句合成 + 边播边合成"实际不可用。
2. **"本地台词包"（voicecache.js）是死代码：`beginWrite()` 之后从没有 `commit()`**（`speech.js:247`，全库无 commit 调用）。
   结果：`voicepack` 目录 0 文件、日志里 `TTS 本地包` 命中 **0 次**，P0-5（预合成固定台词、断网可播）在桥侧根本不可能达成；
   README/注释里"第二次开始完全不出外网"的承诺不成立。
3. **HTTP 动作面可被任意网页驱动，且能链到进程执行。** 动作路由不限制方法（GET 生效）、不校验 `Content-Type`、
   `authorized()` 只按 `remoteAddress` 判本机、只读响应带 `ACAO:*`；实测 `GET /say?text=…` → 200，
   `POST /api/config`（`text/plain` + JSON body）→ 200 并落盘。`/api/config` 无键白名单，可写
   `asrCommand`/`ttsPython`/`ttsFfmpeg`/`workspaceDir`，这些值随后分别进入 `exec()`/`spawn()`
   （`asr.js:126`、`tts_edge.js:72,80`）→ **CSRF → 任意进程执行 / 任意路径写盘**（与 E-06 同源，本文件补"配置→spawn"链）。
4. **配置分层仍然完全不可见（TODO P4-1 未做）。** 实测 `POST /api/config` 写 `maxReplyChars=55` 返回 `ok:true`，
   回读仍是 **240**（被插件自带 `cordis.patch.yml:19` 覆盖）；运行态 `config.json` 写 `brain=llm`，实际跑的是
   `brain=session`。启动日志只打路径/存储统计，不打印任何"有效值 + 来源层"；`/api/diag` **404**（P4-4 未做）。
5. **契约出现了"反向漂移"：设备已经有的能力，桥仍宣称没有。** 固件 `proto.cc:468-479` + `app_ui.cc:289-300`
   已实现 `play`/`stop` 下行与 `storage`/`mp3_player`（TF 卡挂载 + 本地播放），而桥 `contract.js:42-50` 只有 7 条下行、
   `device.send()` 会拒绝 `play`；TODO P1-4 里"v2 没实现 SdInit()"的文本**已过期**（源码 11-01 05:11 已有 `storage.cc`，
   `app_main.cc:53` 调 `storage::Init()`）。反过来，桥允许 `say` 文本 2000 字符，而固件下行 JSON 缓冲只有 560 B
   （`app_ui.cc:255-259`）→ 长句会在设备侧被截成非法 JSON、**静默丢字幕**。

| HTTP 路由 | 文档：只读 8 / 动作 6 / gone 2（501） | `http.js:116-218` 实现齐全；`/api/state` 等与文档一致 | — | **实现比文档宽**：动作接受 GET/任意 Content-Type（BR-24），文档未写 → 安全文档滞后 |

**跨层额外发现（桥侧可缓解）**：固件 `app_ui.cc:262-264` 在 JSON 解析前对整帧做 `strstr`，
所以 `say.text` 里只要出现 `"shot"` / `"ping"` / `"welcome"` 字面量（例如用户让它念一句含 `shot` 的英文），
设备会转去拍照/回 pong/忽略，**文本不显示**。桥目前不转义/不限制（`protocol.js:174-177`）。
建议桥侧在 `say()` 里对这三个子串做不可见转义（如零宽字符）或拒绝并提示（P2/风险，未单列以控制表长）。

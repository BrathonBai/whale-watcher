## 纪律

1. 新文档命名：`<主题>-YYYY-MM-DD.md`；跨天的长期文档不带日期（如 `端云具身Agent-落地设计.md`）。
2. 结论要带证据：实测日志、截图、命令输出。**没有当场证据的写"待验证"**。
3. 文档与实践冲突时，以设备实测 / 日志为准，并回来改文档。
4. 增删文件后同步本索引与根目录 `README.md` §2。

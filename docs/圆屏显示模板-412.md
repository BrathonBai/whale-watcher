# 圆屏显示模板（412×412）与画面设计约束

> 用途：给鲸鲸（SenseCAP Watcher，**412×412 圆屏**）做画面设计时，先在这套模板里把构图、字幕、
> 状态区和裁切问题定下来，再进固件实现。坐标与固件像素 **1:1**，不是等比示意。
>
> 文件：
> - **[`design/preview/round-template.html`](../design/preview/round-template.html)** —— 交互模板（浏览器打开即可）：
>   预设画面、字幕拟合、安全圆/弦长/圆外遮罩/倾角辅助线、导出 SVG。
> - **[`design/round-412-template.svg`](../design/round-412-template.svg)** —— 静态辅助线，可直接拖进 Figma / Illustrator 叠加。
> - 现有视觉参考：[`design/ui_mock.py`](../design/ui_mock.py)（9 态视觉稿）与 `design/out/`（PNG 联排）。

## 1. 先记住三条会直接决定"能不能实现"的现实

1. **字体只有 16×16 位图字体**（`text_draw.h: kCellW/kCellH=16`，字形数据 `font16.h`）。
   没有任意字号、粗体、斜体、描边、投影。设计稿里的 30/46/62px 大标题**目前画不出来**；
   要么用图形/图标表达，要么先做新的字模资源（`tools/gen_font.py`，再改 `text_draw` 支持多字号）。
2. **圆外四角永远不可见。** 屏幕可视区就是半径 206 的圆；设计元素放角落等于没画。
3. **字幕 4 行、每行 13 个汉字（208px）**，超过 4 行会自动翻页（3.5s/页），不是一屏塞下。

## 2. 坐标与分区（与固件一致，直接抄）

| 项 | 数值 | 来源 |
|---|---|---|
| 屏幕 | 412×412，圆心 (206,206)，可视半径 206 | `render.h: kScreenW/H` |
| 安全圆 | r=186（四周留 20px，推荐内容边界） | 模板约定 |
| chrome 细环 | r=178 | `render.cc: DrawChrome()` |
| 刻度盘 | 60 格，r=161→167，每 6° | 同上 |
| 角色区 | y=96 起，高 180；clip 常见宽 160 / 156 / 137（居中） | `render.cc: kPetTopY` |
| 角色区底 | y=276（再往下是字幕区） | 96+180 |
| 字幕气泡外框 | x 92→319，y 304→382（227×78，圆角 12） | `render.cc: DrawTextPage()` |
| 字幕文字区 | x=102，y=312 起，宽 208，行高 16，共 4 行 | `render.h: kTextX/Y/W/LineH/Lines` |
| 字基线 | 每格第 13 行 | `text_draw.h` |
| 菜单 | 与字幕同一区域，最多 4 项，无滚动 | `render.cc: DrawMenu()` |

## 3. 圆内可用宽度：按 y 查（内容越靠边，能用的宽度越窄）

弦宽 = `2·√(r² − (y−206)²)`；字幕/角色内容按**安全圆 r=186** 设计；只有装饰可以到 r=206。

| y | 可视弦宽 (r=206) | 安全弦宽 (r=186) | 208px 内容是否放得下 |
|---|---|---|---|
| 304（气泡上沿） | 362 | 316 | ✅ |
| 312（第 1 行顶） | 353 | 306 | ✅ |
| 328（第 2 行） | 332 | 281 | ✅ |
| 344（第 3 行） | 306 | 249 | ✅ |
| 360（第 4 行） | 274 | **209** | ✅ 刚好（208） |
| 376（第 4 行底） | 233 | 151 | ⚠️ 超出安全圆 28px/侧，**但仍在可视圆内** |
| 382（气泡下沿） | 214 | 120 | ⚠️ 只靠圆角遮住 |

**结论**：现在字幕最后一行已经用掉了底部的安全余量（在安全圆外、可视圆内）。
如果新设计给屏幕加内缩边框、贴膜或更厚的 bezel，**第一个被裁的就是第 4 行字幕**。
更稳的改法是：字幕改 3 行/页（y 312–360），或把气泡上移 8–16px。

## 4. 常见画面问题与对应规则

| 症状 | 原因 | 规则 |
|---|---|---|
| 四角元素消失 | 圆外不可见 | 内容左/右边界 ≤ r=186 圆内；用模板的"圆外遮罩"检查 |
| 字幕贴边或被裁 | 第 4 行落在安全圆外 | 最宽内容控制在 208px；或 3 行/页；底边别超过 y=376 |
| 大标题显示不出来 | 固件只有 16px 位图字 | 用 16px 字 + 图形/留白做层级；大字需先加字模资源 |
| 长回复被截断感 | 4 行/页 + 3.5s 翻页 | 设计稿最多按 4 行构图；模型回复可能 60 字（约 60 汉字 → 5 行） |
| 角色被字幕压住 | 角色区 y96–276、字幕 y304 起 | 角色 clip 底边不要超过 276；字幕气泡别上移到 300 以上 |
| 菜单项放不下 | 4 项/页，16px 行高 | 超过 4 项要分页/滚动逻辑（当前固件未实现），设计阶段就限定 |
| 顶部状态区与刻度打架 | chrome r=178 + 刻度 r161–167 | 状态信息只能放 r<160 内，或放在角色区上方 60–92 的窄带 |
| 元素在倾斜后不对称 | 实机安装倾角 2.65°，UI 会反向补偿 | 设计稿保持正交；贴边元素两侧各留 ≥12px 抗补偿误差 |
| 深色下发灰、对比不足 | 面板 RGB565 + 实际亮度 | 正文用 #EBF3F5，次要 #92A2A9，弱信息 #54636A；彩色仅用于状态 |
| 动效"卡" | 待机 9fps、说话降到 5fps；整帧 412×412 刷新贵 | 装饰动效按 5–9fps 设计；避免每秒整屏重绘 |

## 5. 怎么用模板

1. 浏览器打开 `design/preview/round-template.html`：
   - 左侧是 412×412 屏幕（按 1.6× 显示，坐标 1:1）；
   - 右侧选预设（待机/倾听/讲述/菜单/通知/离线/错误/长文压力），或直接改文本框模拟字幕；
   - 勾选"圆外遮罩"看裁切；勾"字幕行弦长标注"看每行可用宽度；勾"2.65° 安装倾角参考"看倾斜影响。
2. 做稿时把 `design/round-412-template.svg` 叠在设计稿最上层（Figma：Place image → 锁定）。
3. 定稿前用模板的"导出 SVG"导出当前画面，作为开发对照；或在模板里直接标注坐标。
4. 交付固件前过一遍 §4 的表 + 下面清单。

## 6. 设计交付清单（勾完再进实现）

- [ ] 所有文字都是 **16px 字格**能表达的（中文 16px/字、ASCII 半宽 8px）
- [ ] 正文/字幕内容在 **r=186 安全圆**内；第 4 行字幕有心理准备会用到安全圆外
- [ ] 字幕最长行 ≤ **208px（13 汉字）**，总行数按 4 行/页构图
- [ ] 角色 clip 在 **y=96–276** 内，宽 ≤ 208（160/156/137 是已有素材）
- [ ] 顶部状态 / 角标没有压到 **r=178 环和刻度**（或明确接受被环压住）
- [ ] 菜单 ≤ 4 项；超过则先定义分页规则
- [ ] 动效按 **5–9 fps** 设计，且不依赖整屏重绘
- [ ] 颜色只用调色板（`#06090B/#141F26/#1E2E36/#EBF3F5/#92A2A9/#54636A` + 状态色）
- [ ] 倾斜 2.65° 后，对称元素两侧仍有余量（≥12px）
